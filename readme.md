# Individual Assignment 2

This is my second individual assignment in HTML and CSS at Kristiania.

I made a website showing a squad list for the Toronto Maple Leafs. The squad list has 15 player cards with pictures and information about each player.

For the optional bonus assignment, I created a second page showing the 2025–2026 NHL standings for all 32 teams, divided into two conferences and four divisions.

I used HTML and CSS to create both pages, make the layouts responsive, and add navigation between the squad list and league standings. The standings tables can be scrolled horizontally on smaller screens.
